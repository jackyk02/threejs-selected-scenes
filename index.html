Seventeen kept scenes

Three.js scenes written in one shot by Inkling-Small 2, kept from the longer shortlist. Each was the top-scoring sample for its prompt under LLM-as-a-Verifier. Select a still to run the scene live, then use the strip above it to switch to any of the other samples generated for the same prompt.

Reward is the weighted verifier score in [0, 1]; bars show the three verifier criteria. The judge line gives standard LLM-as-a-Judge grades from the same model, each scene graded alone on a 1–10 scale for aesthetic, code and coherence, one run per grade. “Judge agrees” means the selected scene also has the highest weighted judge grade in its group. Run 1 and Run 2 scenes come from RL training steps, Bench 200 scenes from the base model, and the two use different reward weights, so compare rewards within a source.
